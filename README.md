# 📱 AR Focus App — Augmented Reality Focus Timer

A modern productivity tool that uses **augmented reality** to help you stay focused.  
This project combines clean UI, AR interaction, and minimalistic design to deliver a unique, immersive focus-timer experience.

## ✨ Features
- 🕒 **AR-Based Focus Timer** — the timer appears in augmented reality for a more engaging workflow  
- 🎨 **Clean Minimalistic UI** — distraction-free and visually appealing  
- 📱 **Mobile-Friendly** — optimized for phones supporting WebAR  
- ⚡ **Lightweight & Fast** — works instantly in the browser, no backend required  
- 🎯 **Simple Controls** — start, stop, and reset timer actions  

## 🛠️ Technologies Used
- **HTML5** — structure & layout  
- **CSS3** — responsive styling and clean UI  
- **JavaScript** — timer logic + AR functionality  
- **AR.js / WebAR** — camera tracking and augmented reality rendering  

## 🚀 Getting Started

You can run the project locally without any additional setup:

```bash
git clone https://github.com/Zhanel77/AR-Focus-App
cd AR-Focus-App
open index.html
```
Or simply drag-and-drop the folder into your browser.

## 🧠 How It Works
The app uses WebAR technologies to render a digital timer into your real-world environment:

- The camera detects an AR marker or surface

- The app renders a 3D timer element

- The user controls the timer using simple UI buttons

- Ideal for studying, meditation, or deep work sessions

- This approach creates a sense of presence and immersion, making focus sessions more engaging.
